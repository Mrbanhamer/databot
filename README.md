About
Purpose:
# databot
A bot that scrapes data from selected subreddits, stores the data in a file, and generates graphs based on the collected information.

Libraries used:
os
json
matplotlib
request
colorama
(pathlib)

Testing:
(pytest)

Installation
Clone the repository:
git clone https://github.com/Mrbanhamer/databot.git
cd databot

Create and activate a virtual environment
Windows:
python -m venv venv
venv\Scripts\activate

macOS / Linux:
python3 -m venv venv
source venv/bin/activate

Install dependencies:
pip install -r requirements.txt

Usage
Run the project:
python3 main.py
